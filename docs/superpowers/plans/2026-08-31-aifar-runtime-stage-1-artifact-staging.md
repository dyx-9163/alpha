# AIFAR Runtime Stage 1 Artifact Staging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the initial AIFAR Runtime install upload every executable input into an operation-scoped directory, verify its SHA-256 and size on the target server, and fail before the install script runs when integrity cannot be proven.

**Architecture:** Add a generic fail-closed verified-upload primitive to `uploadkit`, then add an AIFAR-specific staging-area boundary under `INSTALL_ROOT/.aifar-lifecycle/install-RELEASE_ID/stage`. The current Worker and install flow remain in place for stage 1; the persistent lifecycle table starts in stage 2. The install template's active-directory replacement is deliberately unchanged until stage 3.

**Tech Stack:** Go 1.24, existing SSH `installerkit.Remote`, SHA-256, POSIX shell on openEuler/Linux, current AIFAR Worker/task logging, SQLite-backed app instance state.

**Spec:** `docs/superpowers/specs/2026-08-31-aifar-runtime-single-server-lifecycle-reliability-design.md`

## Global Constraints

- Scope is only the single-server AIFAR Runtime initial install upload path and the reusable verified-upload primitive it needs.
- A SHA-256 or size mismatch must prompt and stop; there is no bypass flag.
- Bundle archive, optional `aifar-agent` binary, and generated install script must all be verified before `sh install-aifar.sh` runs.
- Agent `Accepted` semantics and Runtime Ready/Available success gating are not changed in stage 1.
- `templates/install.sh` active-directory mutation is not changed in stage 1; atomic activation belongs to stage 3.
- All target paths are generated by code under the configured AIFAR install root. No API accepts a free remote path or shell command.
- Failure cleanup may remove only the current operation staging directory after a real-path containment check.
- Logs, task errors, and audit data must not contain credentials, env contents, private keys, tokens, or full connection strings.
- New user-visible messages are provided in Chinese and English.
- Tests use fake remotes; they never connect to a real SSH server or Docker daemon.
- The feature is not accepted until automated checks pass, code and SDD evidence are pushed, the user completes manual validation, and the user explicitly replies “继续”.
- Preserve the existing untracked `memory/2026-08-28.md`; never stage it as part of this feature.

```go
var installStageSegmentPattern = regexp.MustCompile(`^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$`)

func newInstallArtifactStage(installRoot, releaseID, archiveName, agentName string) (installArtifactStage, error) {
    root := path.Clean(strings.TrimSpace(installRoot))
    if root == "." || root == "/" || !path.IsAbs(root) {
        return installArtifactStage{}, errors.New("AIFAR install staging root is invalid")
    }
    if !installStageSegmentPattern.MatchString(releaseID) {
        return installArtifactStage{}, errors.New("AIFAR install staging release is invalid")
    }
    if !safeInstallStageFileName(archiveName) || (agentName != "" && !safeInstallStageFileName(agentName)) {
        return installArtifactStage{}, errors.New("AIFAR install staging file name is invalid")
    }
    stageRoot := path.Join(root, ".aifar-lifecycle", "install-"+releaseID, "stage")
    stage := installArtifactStage{
        Root:          stageRoot,
        ArchiveRemote: path.Join(stageRoot, archiveName),
        ScriptRemote:  path.Join(stageRoot, "install-aifar.sh"),
    }
    if agentName != "" {
        stage.AgentRemote = path.Join(stageRoot, agentName)
    }
    return stage, nil
}

func safeInstallStageFileName(value string) bool {
    return value != "" && value != "." && value != ".." && path.Base(value) == value && !strings.ContainsAny(value, `/\\`)
}
```

Use only stable non-secret error text. Do not include the caller-provided path in validation errors.

- [ ] **Step 4: Implement local digest and strict path validation**


Rules:

- `localSHA256` streams through `sha256.New()` and `io.Copy`; it does not load the artifact into memory.
- `stageRoot` and `remotePath` must be absolute POSIX paths.
- `stageRoot` cannot be `/`.
- `remotePath` must be a strict descendant of `stageRoot`, using `path.Clean` and the `root + "/"` boundary.
- The proof parser accepts exactly one line matching `^AIFAR_UPLOAD_VERIFY ([a-f0-9]{64}) ([0-9]+)$`; duplicate or unrelated marker lines fail closed.
- A size larger than `math.MaxInt64` fails parsing.

- [ ] **Step 5: Implement the target verification command and typed errors**

Use shell-quoted constants and the following command protocol:

```sh
set -eu
target='...'
stage_root='...'
expected_sha256='...'
expected_size='...'
case "$target" in
  "$stage_root"/*) ;;
  *) echo "uploaded file escaped staging root" >&2; exit 64 ;;
esac
actual_sha256="$(sha256sum -- "$target" | awk '{print $1}')"
actual_size="$(stat -c %s -- "$target")"
printf 'AIFAR_UPLOAD_VERIFY %s %s\n' "$actual_sha256" "$actual_size"
if [ "$actual_sha256" != "$expected_sha256" ] || [ "$actual_size" != "$expected_size" ]; then
  rm -f -- "$target"
  exit 65
fi
```

Implementation order:

```go
func UploadVerified(...) (Verification, error) {
    if err := validateVerifiedRemotePath(file.StageRoot, file.RemotePath); err != nil {
        return Verification{}, fmt.Errorf("%w: %v", ErrVerificationFailed, err)
    }
    expectedSHA, expectedSize, err := localSHA256(file.LocalPath)
    if err != nil {
        return Verification{}, fmt.Errorf("%w: calculate local checksum: %v", ErrVerificationFailed, err)
    }
    if err := Upload(ctx, remote, server, file.File, log); err != nil {
        return Verification{}, err
    }
    result, runErr := remote.Run(ctx, server, verificationCommand(...))
    installerkit.LogCommandResult(result, runErr, log)
    proof, proofErr := parseVerificationMarker(result.Stdout)
    if proofErr != nil {
        return Verification{}, fmt.Errorf("%w: target did not return a valid proof", ErrVerificationFailed)
    }
    if proof.SHA256 != expectedSHA || proof.Size != expectedSize {
        return Verification{}, fmt.Errorf("%w", ErrChecksumMismatch)
    }
    if runErr != nil {
        return Verification{}, fmt.Errorf("%w: target verification command failed", ErrVerificationFailed)
    }
    if log != nil && strings.TrimSpace(file.VerificationLogMessage) != "" {
        log.Info(file.VerificationLogMessage, file.VerificationLogArgs...)
    }
    return proof, nil
}
```

Do not include expected/actual hashes or local/remote absolute paths in returned user-visible errors. They may appear only in test assertions and structured debug evidence added in later stages.
