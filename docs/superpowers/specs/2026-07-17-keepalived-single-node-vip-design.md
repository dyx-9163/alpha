# Keepalived 单节点 VIP 配置设计

## 目标

在服务器 `192.168.74.132` 的网卡 `ens160` 上，由已安装的 Keepalived 2.4.2 管理 VIP `192.168.74.130/24`。

## 方案

- 节点角色：单节点 `MASTER`。
- VRRP 接口：`ens160`。
- VIP：`192.168.74.130/24`。
- 健康条件：VRRP 实例使用 `ens160` 作为自身接口，Keepalived 会自动跟踪该接口；网卡失效时节点进入故障状态并移除 VIP，不重复配置 `track_interface ens160`。
- 服务健康：本阶段不配置 HTTP/TCP 业务健康检查。
- 高可用边界：没有第二台 `BACKUP` 节点，因此服务器宕机时 VIP 不会漂移到其他服务器。

## 安全与实施

1. 配置前检查 VIP 当前未被本机使用，并通过 ARP 探测尽力确认局域网内没有其他主机占用。
2. 备份已有正式配置；若正式配置不存在，则创建新配置。
3. 使用 `/aifar/apps/keepalived/sbin/keepalived -t` 校验配置，通过后才启用服务。
4. 启动后验证服务状态、`ens160` 上的 VIP、进程和日志。
5. 若启动或验证失败，停止服务并恢复原配置。

## 验收标准

- `keepalived.service` 为 `active`。
- `ip address show dev ens160` 显示 `192.168.74.130/24`。
- 配置语法检查退出码为 0。
- 本机可以通过 VIP 完成基础连通性检查。
