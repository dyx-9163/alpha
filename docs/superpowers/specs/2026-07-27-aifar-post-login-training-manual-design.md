# AIFAR 登录后功能培训手册设计

## 1. 目标

制作一份面向日常操作员和实施运维工程师的中文图文培训手册。手册只覆盖用户登录 AIFAR 后可见、可执行和可核验的产品功能，不包含 AIFAR 自身的安装、启动、升级、打包或源码开发。

最终交付为可编辑的 Word 文档，使用当前分支的真实页面截图，并完成逐页视觉检查。

## 2. 读者与使用场景

- 日常操作员：完成服务器查看、应用部署、状态检查、任务跟踪和常规日志查看。
- 实施运维工程师：完成服务器接入、实例检测、Runtime 运维、凭据与终端操作、异常定位和高风险操作复核。
- 培训讲师：按任务主线授课，并使用文末练习和验收清单组织实操。
- 值班人员：通过菜单速查和常见问题章节快速定位入口与处置边界。

## 3. 内容范围

### 3.1 纳入范围

- 登录后的界面、导航、状态和权限认知。
- 仪表盘、服务器、应用商店、容器、AIFAR Runtime、数据库、Nacos、存储、凭据、终端、任务、工具箱、审计和设置。
- 日常操作主线：服务器接入与探测、应用部署、任务跟踪、结果确认。
- 运维场景：状态检查、日志排错、扩缩容、重启并读取新配置、取消任务、实例检测、删除或卸载。
- 安全原则、风险操作、能力边界、常见问题、培训练习、验收清单和菜单速查。

### 3.2 排除范围

- AIFAR 服务端的安装、启动、停止、升级、备份和恢复。
- 源码开发、构建、测试、打包和发布流程。
- 未在当前产品中落地的规划能力。
- 依赖真实生产凭据、真实业务数据或不可恢复变更的演示。

## 4. 信息架构

手册采用任务场景式主线，附菜单快速索引。

1. 封面、版本说明与适用对象。
2. 培训目标、角色分工与安全原则。
3. 登录后的界面、导航、状态和权限认知。
4. 日常操作主线：服务器接入、探测、应用部署、任务跟踪、结果确认。
5. 功能模块详解。
6. 常见运维场景。
7. 高风险操作与当前能力边界。
8. 常见问题与故障定位。
9. 培训练习、验收清单与菜单速查表。

每个操作流程统一使用“目的—适用角色—前提条件—操作步骤—预期结果—风险提示”的结构。正文以操作员必学内容为主，实施细节和排障原理使用“运维进阶”标识。

## 5. 截图策略

- 启动当前仓库的本地 AIFAR 开发环境，通过真实页面采集截图。
- 截图覆盖主要导航页面、关键弹窗、任务状态和运维入口。
- 对必须依赖真实 Linux、Docker、SSH 或完整离线资源才能出现的画面，不伪造成功状态；优先采用真实空状态、配置状态或当前可达页面，并说明环境前提。
- 截图不得包含密码、私钥、Token、完整敏感连接信息或真实生产数据。
- 对需要强调的入口进行克制的编号或框选标注；一张图只承担一个主要说明目标。
- 截图图注包含页面名称、用途和必要的环境说明。

## 6. 事实与能力边界

- 内容以当前分支实际菜单、页面文案、接口和已完成能力为准。
- 所有状态变更应通过任务和审计理解，不把异步任务描述成同步完成。
- Runtime 的停止任务与服务下线是不同概念：停止任务取消当前 pending/running worker 任务，下线把服务期望副本数调整为 0。
- Runtime 的“全部重启（读取新配置）”只作用于当前选中实例，并保持已下线服务不被重新启动。
- 终端支持多会话；切换菜单可保持连接，同屏最多展示 4 个会话，刷新、关闭浏览器或退出登录会清理会话。
- Storage 的 bucket、object、user、access-key、replica 当前属于控制面记录，不描述为完整 MinIO API 或 mc 实操能力。
- 删除部署服务需要按当前产品规则完成凭据确认；手册必须将删除、卸载、凭据、终端和存储操作标记为高风险或受限操作。

## 7. 视觉设计

- 文档类型：企业内部图文培训手册。
- 页面：A4 纵向，适合屏幕阅读和打印。
- 字体：中文使用微软雅黑或等线，英文和数字使用兼容的无衬线字体。
- 色彩：蓝灰色主层级，与 AIFAR 界面风格呼应；橙色用于警告，绿色用于成功或核验通过。
- 章节：首页突出学习目标、适用角色和预计学习成果。
- 图片：保持可读尺寸，使用编号、图注和必要标注，避免在单页堆叠过多小图。
- 信息组件：编号步骤、检查清单、运维进阶框、风险警告框、能力边界说明框和速查表。
- 页眉页脚：页眉显示“AIFAR 登录后功能培训手册”；页脚显示版本、日期和页码。

- 主交付物：`docs/AIFAR登录后功能培训手册.docx`。
- 设计说明：本文件。
- 截图和渲染中间文件仅用于制作与质量检查，不作为默认交付物。

## 9. 验收标准

- 只讲登录后的产品功能，不混入安装、升级或源码开发内容。
- 同时满足操作员学习和实施运维查阅需求，角色层次清晰。
- 当前所有主要菜单均有说明，核心任务主线可独立完成培训。
- 关键流程包含真实截图、步骤、预期结果和风险提示。
- 不泄露敏感数据，不虚构现场成功状态。
- 已知产品边界表述准确，尤其是 Storage 控制面记录、Runtime 任务取消、服务下线和配置重读。
- Word 文档无文字遮挡、图片过小、表格溢出、页眉页脚错位和明显孤行。
- 使用文档渲染工具输出逐页图片并完成视觉复核；如环境确实缺少渲染能力，则进行结构检查并在交付时明确说明。
