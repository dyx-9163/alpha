# 隐藏二级管理入口设计

## 目标

暂时收敛数据库、Nacos 和对象存储页面的可见管理入口，只保留各页面的“实例”标签；对象存储页面同时隐藏清理策略的“应用清理策略”和“停用策略”按钮。

## 范围

- 数据库页面隐藏“部署记录”和“设置”标签。
- Nacos 页面隐藏“配置发布”“部署记录”和“配置”标签。
- 对象存储页面隐藏“Bucket”“对象”“访问控制”“复制配置”“部署记录”和“配置”标签。
- 对象存储实例工具栏保留 Bucket、Prefix、30/60/180 天、天数输入和“统计可清理”，只隐藏策略应用与停用按钮。

## 实现方式

直接从三个 Vue 页面模板中移除对应的 `el-tab-pane` 和按钮节点。保留页面脚本、后端 API、状态数据、历史记录和国际化文案，使入口后续可以低成本恢复，不引入新的功能开关或 CSS 隐藏规则。

## 行为与数据边界

- 页面初始标签仍为 `instances`，现有实例查询与实时刷新流程不变。
- 被隐藏标签对应的模板分支和业务函数暂时保留，但普通用户无法从页面标签进入。
- 不修改 `/api/v2`、数据库结构、权限模型、任务流程或远端服务。
- 不删除任何已保存的配置、部署记录或 MinIO 清理策略。

## 验证

- 添加一个小型页面入口清单模块，由三个页面使用并通过 Vitest 验证各页面只返回 `instances`。
- 通过前端单元测试验证入口清单。
- 运行 `pnpm test:web`、`pnpm web:build` 和 `git diff --check`。
