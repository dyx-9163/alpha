# AIFAR Runtime 按服务器本地日期原始日志导出设计

## 目标

把现有 Runtime 诊断归档从“按时间窗解析、筛选并脱敏日志记录”改为“按一台服务器的一个本地日期直接快照宿主机日志文件”，保证归档中的每个日志文件与任务捕获的服务器源文件字节一致。导出不使用 `docker logs`，不解析记录时间戳，不脱敏、不改写日志内容。

## 用户契约

- 每个任务固定绑定一个 AIFAR Runtime 实例，因此只对应一台已登记服务器。
- 请求只接受一个 `YYYY-MM-DD` 服务器本地日期和至少一个已启用服务。
- 未来日期拒绝；服务器当天和历史日期允许。
- 历史日期只选择相对路径中包含所选日期的轮转日志。
- 服务器当天选择相对路径中包含当天日期的日志，并额外选择各服务日志根目录最外层的活动日志。
- 归档保持 `services/<service>/<server-relative-path>`，不增加人为目录层级。
- 没有候选日志时估算不可执行，导出不生成空成功归档。

## 日期与持久化

目标机估算脚本读取服务器时区，并把请求的本地日期换算为该日期的 UTC 起止边界。`diagnostic_exports` 新增 `local_date`，同时继续保存现有 `since_at`、`until_at`，以兼容列表、历史记录和既有归档下载。旧记录的 `local_date` 为空，仍可下载和删除。

估算协议升级为 V3，总记录返回服务器时区、本地日期、日界 Unix 时间和是否当天。HTTP 创建任务只能使用估算返回的日界，不能由浏览器时区计算。

## 原始字节快照

每个候选文件必须是服务日志根目录内的普通非软链接文件，名称符合 `.log` 或 `.log.*`，且路径不含隐藏、配置、数据库或凭据敏感目录。远端 helper 对每个文件执行：

1. 打开只读文件描述符并记录 device、inode、初始字节数。
2. 从该描述符读取恰好初始长度，通过同一数据流写入暂存文件并计算源快照 SHA256。
3. 校验暂存文件长度和 SHA256。
4. 重新计算源文件已捕获前缀 SHA256，防止复制期间原位改写。
5. 校验路径仍指向相同 device/inode。
6. 历史日期要求最终长度等于初始长度；当天允许相同文件继续追加，但最终长度不得小于初始长度。
7. 任一校验失败则整个任务失败，不发布部分成功归档。

因此，当天活动文件的一致性定义为：归档文件与任务打开源文件时捕获的固定长度前缀逐字节一致。任务期间追加的字节不进入本次归档。

## 归档与清单

继续使用现有 SSH 流式传输、面板侧 `.partial`、大小/SHA256 校验、原子提交、24 小时保留和 5 GiB 总配额。`manifest.json` 升级为原始快照格式，记录：

- `localDate`、`serverTimezone`、`snapshotStartedAt`；
- 每个源的 service、sourcePath、device、inode、capturedBytes；
- `sourceSnapshotSha256` 与 `archiveEntrySha256`；
- `activeSnapshot`，表示是否采用允许追加的当天规则。

归档不再执行记录过滤、脱敏扫描或 Docker 日志收集。Runtime/容器/主机状态摘要仍可保留为诊断辅助文件，但不参与“日志字节一致”声明。

## UI 与 API

- 请求体从 `sinceAt/untilAt` 改为 `localDate`。
- 导出弹窗使用单日期选择器，默认显示浏览器今天；最终合法性由目标服务器估算确认。
- 估算结果展示服务器时区、服务器本地日期、候选文件数和候选总字节。
- 明确提示原始日志未脱敏，可能包含敏感信息；当天导出是任务开始时的固定长度快照。
- 列表优先展示 `localDate`；旧记录回退展示原时间范围。

## 错误与安全

- 日期格式错误、未来日期、服务/服务器不匹配、无候选文件均拒绝执行。
- 文件超限、总扫描超限、源文件截断/替换/轮转、快照哈希不一致、归档校验失败均使任务失败并清理远端临时目录与面板 `.partial`。
- 继续拒绝软链接、路径逃逸、隐藏路径以及名称含 config/database/credential/secret/password/token/private/keystore/truststore 的路径。
- 原始日志可能含敏感内容；权限继续沿用 `rbac.AppsManage`，任务与审计链路保持不变。

## 验证

- Store 迁移和旧记录兼容测试。
- API 单日期请求、未来日期和任务单服务器归属测试。
- V3 估算协议与日界测试。
- Linux shell 行为测试覆盖历史日期、当天顶层活动日志、当天日期文件、排除其他日期、追加允许、截断/替换失败、逐文件 SHA256 一致和无候选失败。
- 前端交互测试覆盖默认日期、请求指纹、单日期 payload 和原始日志风险文案。
- 最终运行后端全集、前端全集和 Web/后端构建；不更新 `aifar-agent`，不执行离线打包，不推送。
