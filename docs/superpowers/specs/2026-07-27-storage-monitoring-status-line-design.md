# MinIO 实时监测状态栏设计

## 目标

在对象存储（MinIO）页面页头与“实例”标签之间增加与 Nacos 页面一致的实时监测状态栏，让用户直接看到已登记实例数量、后端推送等待状态和最近监测时间。

## 界面与数据

- 状态栏沿用现有 `aifar-panel status-line` 结构和样式，不新增组件或样式令牌。
- 第一项显示 `已登记 X 个 MinIO 实例`，数量仅统计当前对象存储页面中 `app === 'minio'` 的实例。
- 第二项在用户具备 `apps.manage` 权限时显示 `等待后端推送`；无权限时显示对象存储监测权限提示，行为与 Nacos 页面一致。
- 第三项显示 `最近监测 HH:mm:ss`，时间取所有 MinIO 实例实时快照中最新的 `collectedAt`，没有时回退到 `updatedAt`；没有任何有效快照时间时隐藏该项。
- 状态栏位于页面标题区之后、“实例”标签条之前，不改变下方搜索、清理估算和实例卡片布局。

## 实现边界

- 在 `StorageView.vue` 内增加状态栏模板、MinIO 实例筛选、最新快照时间和监测状态文案计算。
- 增加 `storage.instanceCount`、`storage.backendPushReady`、`storage.lastMonitoredAt`、`storage.monitorPermissionRequired` 的中英文文案。
- 不抽取共享组件，不修改 Nacos 页面，不新增或修改后端接口，不改变实时推送机制。

## 错误与空状态

- 实例接口失败时继续沿用页面现有的保留旧数据策略。
- 没有 MinIO 实例时显示 `已登记 0 个 MinIO 实例`，不显示最近监测时间。
- 快照时间无法解析时忽略该时间，不影响页面其他内容渲染。

## 测试与验收

- 先增加失败测试，覆盖状态栏字段顺序、仅统计 MinIO 实例和最新快照时间选择。
- 运行相关前端测试、完整 `pnpm test:web` 和 `pnpm web:build`。
- 在本地页面确认状态栏位置、文案、实例数和最近监测时间与 Nacos 一致。

## 非目标

- 不增加轮询、手动监测按钮或新的 SSE 事件。
- 不重构数据库、Nacos 与对象存储页面的公共布局。
- 不修改 MinIO 实例卡片、清理策略或部署入口。
